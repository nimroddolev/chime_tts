Playback Options

Set the default chimes, audio timing, transitions, cleanup behaviour, and MP3 cover art used for announcements.

Default Offset​

The default offset duration (in milliseconds) between chimes and TTS audio. Positive values introduce a delay, while negative values overlap the audio segments. It is used when an action omits offset or delay; an action value takes precedence.

Default Value:450
Required:No

Default Start Chime​

Set an optional chime to play before generated speech. It is applied when an action omits chime_path; an action value, including an empty value that disables the start chime, takes precedence.

Default Value:None
Required:No

Default End Chime​

Set an optional chime to play after generated speech. It is applied when an action omits end_chime_path; an action value, including an empty value that disables the end chime, takes precedence.

Default Value:None
Required:No

Default Crossfade​

Set the default crossfade duration between audio segments. It is used when an action omits crossfade; an action value takes precedence. A negative offset overlays segments; crossfade controls how one segment fades into the next.

Default Value:0
Required:No

Default Initial Delay (Beta)​

Beta

The initial_delay default and action parameter are beta features and may change between releases.

Set the default silence duration, in milliseconds, to prepend to generated audio before any start chime or TTS. It is used when an action omits initial_delay; an action value takes precedence.

Default Value:0
Required:No

Fade Transition​

The duration (in milliseconds) to fade out the now playing audio before an announcement, and then fade it back in after the announcement is completed.

This applies to chime_tts.say action calls when the announce or fade_audio parameters are used.

Default Value:500
Required:No

Delay Before Removing Temporary Files​

The delay duration after chime_tts.say playback is completed (in milliseconds), before removing the generated temporary audio file.

Default Value:None
Required:No

MP3 Cover Art​

When enabled, adds the Chime TTS logo as the cover art in generated MP3 files.

Default Value:false
Required:No
