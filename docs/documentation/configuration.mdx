# Configuration

The Chime TTS can be configured via the sidebar panel.

:::caution Beta

The Settings Panel workflow is currently in beta. Settings and panel behavior may change between releases.

:::

## Settings Panel overview

Open **Settings → Devices & services → Chime TTS → Configure**. The panel groups TTS defaults and fallback, playback options, audio file folders, action and script defaults, Chimes, Chime Sets, Notification Profiles, and session logs/support information. Use the detailed [Chimes](./chimes), [Chime Sets](./chime-sets), and [Notification Profiles](./notify/) pages rather than duplicating those workflows here.

Restart Home Assistant after adding a TTS provider, changing custom-chime folder paths or contents, adding/removing/renaming a Chime Set, or adding/removing/renaming a Notification Profile. Changing members of an existing Chime Set does not require a restart.

## Configuration sections

- [TTS Defaults & Fallback](./configuration/tts-defaults-fallback): Choose the default TTS provider, language, voice, dialect, and fallback provider.
- [Playback Options](./configuration/playback-options): Set default chimes, audio timing, transitions, cleanup, and MP3 cover art.
- [Audio Files Folders](./configuration/audio-files-folders): Configure generated audio and `chime_tts.say_url` output locations.
- [Action & Script Options](./configuration/action-script-options): Configure action timeouts and default pre- and post-playback scripts.

## Chimes

Manage custom and downloaded chime audio in the panel's **Chimes** section. See [Chimes](./chimes) for chime previews and per-chime offsets.

## Chime Sets

Create reusable groups of chimes and randomly select a member for an action. See [Chime Sets](./chime-sets) for setup, selection, and restart behaviour.

## Notification Profiles

Create reusable Chime TTS notification profiles for automations and scripts. See [Notification Profiles](./notify/) for configuration and YAML examples.

## Logs

Review Chime TTS events and raw logs captured during the current Home Assistant session. See [Logs](./logs) for details.

## Support & Info

Use the panel's **Support & Info** section for documentation, community support, bug reports, feature requests, and project support links.
