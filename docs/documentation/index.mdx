# Chime TTS Documentation


<h2>⚙️ [Configuration](./configuration)</h2>
Use the Chime TTS sidebar panel to configure custom chimes, default values for Chime TTS actions and notification profiles.

<h2>🧰 [Actions](./actions/)</h2>
Review explanations of the parameters used in action calls as well as YAML examples and their resulting audio output.

<h2>🛎️ [Notify](./notify/)</h2>
Set up custom notify entities to use Chime TTS more easily and efficiently in your scripts and automations. Profiles can be managed from the panel or written directly in YAML.

<h2>📋 Action logs and replay</h2>
Use the panel's grouped action logs to review recent service calls and replay eligible playback and notification actions. See the [Replay action](./actions/replay-action) for YAML usage.
