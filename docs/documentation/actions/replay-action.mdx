# `chime_tts.replay` Action

The `chime_tts.replay` action repeats the most recent Chime TTS playback request with its recorded parameters. The Chime TTS sidebar panel also exposes logged actions, including eligible notification-originated actions, for replay.

## Parameters
There are no parameters to set for this action.

## YAML Example

```
action: chime_tts.replay
data:
```
