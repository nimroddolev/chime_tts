# `chime_tts.replay` Action

The `chime_tts.replay` action repeats the most recent Chime TTS playback request with its recorded parameters. It is separate from the sidebar panel's [Logs](../logs), which keeps its own activity entries and can repeat eligible entries from that panel.

## Parameters
There are no parameters to set for this action.

## YAML Example

```
action: chime_tts.replay
data:
```
